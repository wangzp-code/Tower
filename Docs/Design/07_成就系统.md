# 成就系统策划文档

## 一、成就类型

### 1.1 成就分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **战斗成就** | 战斗相关 | 击败特定怪物 |
| **探索成就** | 探索相关 | 到达特定楼层 |
| **收集成就** | 收集相关 | 收集所有碎片 |
| **进化成就** | 进化相关 | 达到特定进化等级 |
| **特殊成就** | 特殊条件 | 完成特定任务 |

### 1.2 成就稀有度

| 稀有度 | 颜色 | 奖励倍率 |
|--------|------|---------|
| 普通 | 灰色 | 1x |
| 稀有 | 蓝色 | 2x |
| 史诗 | 紫色 | 3x |
| 传说 | 金色 | 5x |

### 1.3 成就状态

| 状态 | 说明 |
|------|------|
| **未解锁** | 尚未达成条件 |
| **进行中** | 正在达成条件 |
| **已解锁** | 已达成条件 |
| **已领取** | 已领取奖励 |

## 二、成就配置

### 2.1 成就数据结构

```
Achievement
├── id: string           # 成就ID
├── name: string         # 成就名称
├── description: string  # 成就描述
├── type: string         # 成就类型
├── rarity: string       # 稀有度
├── icon: string         # 图标路径
├── target: int          # 目标数量
├── current: int         # 当前进度
├── reward: Reward       # 奖励内容
└── unlocked: bool       # 是否已解锁
```

### 2.2 成就奖励

| 奖励类型 | 说明 |
|----------|------|
| **进化点** | 直接获得进化点 |
| **金币** | 直接获得金币 |
| **碎片** | 获得稀有碎片 |
| **称号** | 获得特殊称号 |
| **皮肤** | 获得角色皮肤 |

### 2.3 成就列表示例

| ID | 名称 | 描述 | 目标 | 奖励 |
|----|------|------|------|------|
| first_blood | 初猎 | 击败第一个敌人 | 1次 | 10进化点 |
| floor_10 | 深入 | 到达第10层 | 10层 | 50进化点 |
| collector | 收集者 | 收集100个碎片 | 100个 | 稀有碎片 |
| max_evolution | 形态大师 | 达到最高进化等级 | 9级 | 传说碎片 |

## 三、成就解锁机制

### 3.1 解锁流程

```
解锁流程:
1. 玩家完成某个行为
2. 系统检测是否触发成就
3. 更新成就进度
4. 判断是否达成目标
5. 弹出成就解锁提示
6. 发放奖励
```

### 3.2 进度追踪

| 追踪类型 | 说明 |
|----------|------|
| **累计型** | 累计完成次数 |
| **一次性** | 完成一次即可 |
| **条件型** | 满足特定条件 |

### 3.3 解锁提示

```
提示内容:
- 成就图标
- 成就名称
- 成就描述
- 获得奖励
- 动画效果
```

## 四、成就界面

### 4.1 界面结构

```
成就界面:
├── 成就分类标签
│   ├── 战斗
│   ├── 探索
│   ├── 收集
│   └── 特殊
├── 成就列表
│   ├── 成就卡片
│   ├── 进度条
│   └── 状态标识
└── 成就详情弹窗
```

### 4.2 成就卡片

| 元素 | 说明 |
|------|------|
| **图标** | 成就图标 |
| **名称** | 成就名称 |
| **进度条** | 当前进度/目标 |
| **状态** | 锁定/进行中/已解锁 |

### 4.3 详情弹窗

```
弹窗内容:
- 成就图标
- 成就名称
- 成就描述
- 当前进度
- 奖励内容
- 领取按钮(如未领取)
```

## 五、成就统计

### 5.1 统计数据

| 统计项 | 说明 |
|--------|------|
| **总成就数** | 游戏中所有成就数量 |
| **已解锁数** | 玩家已解锁的成就数量 |
| **完成率** | 已解锁/总数 × 100% |
| **获得奖励** | 累计获得的进化点等 |

### 5.2 成就排行

| 排行类型 | 说明 |
|----------|------|
| **个人成就** | 玩家自己的成就进度 |
| **好友排行** | 好友间成就对比 |
| **全服排行** | 服务器成就排名 |
