# 游戏模式与难度曲线设计文档

## 1. 概述

三种游戏模式通过 `ModeFloorCurves.cs` 的曲线数组控制每层的怪物强度、EP产出、污染累积等参数。

来源：`ModeFloorCurves.cs` + `GameMode` 枚举

---

## 2. 曲线参数结构

```
FloorParams {
  hpMult           — 怪物HP倍率（基础HP × hpMult）
  atkMult          — 怪物ATK倍率
  monsterCount     — 本层怪物数量
  eliteRate        — 精英怪出现概率
  epMult           — EP奖励倍率
  fragRate         — 碎片掉落概率
  pollutionPerFloor — 每层自动增加的污染值
  possessPollMult  — 附身时的污染倍率
}
```

### 短局特殊机制

| 层 | 特殊机制 |
|----|---------|
| F1 | 教程（移动/攻击），看门犬HP=1 |

## 4. 远征曲线（20层）

设计目标：4章节渐进深度体验，含战略转折点

| 章节 | 层数 | hpMult范围 | atkMult范围 | 每层污染 |
|------|------|-----------|-----------|---------|
| 前厅 | F1-5 | 0.85~1.05 | 0.80~1.00 | 0 |
| 裂变 | F6-10 | 1.10~1.28 | 1.05~1.18 | 1 |
| 深层 | F11-15 | 1.32~1.48 | 1.20~1.30 | 2~3 |
| 终域 | F16-20 | 1.52~1.65 | 1.33~1.40 | 3~4 |

### 远征固定抉择事件

| 层 | 事件 | 选项A | 选项B |
|----|------|-------|-------|
| F8 | 污染分叉 | ☢污染注入：+25%污染+稀有腐蚀遗产 | ✦净化仪式：-15%污染 |
| F15 | 最终抉择 | ⚔全力一搏：污染→85%+ATK×2 | 🛡稳健通关：+50%HP+污染→30%+DEF+50% |

## 6. 怪物实际数值计算

来源：`CreateMonsterForFloor()`

```
monsterHP = max(20, baseDef.hp × curve.hpMult × random(0.8~1.2) × eliteMult)
monsterATK = max(3, baseDef.atk × curve.atkMult × random(0.8~1.2) × eliteAtkMult)
monsterDEF = baseDef.def × (elite ? 1.3 : 1.0)
```

精英倍率：HP ×1.6, ATK ×1.4, DEF ×1.3
