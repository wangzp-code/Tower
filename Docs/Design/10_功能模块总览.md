# 功能模块总览

## 一、功能模块清单

### 1.1 核心模块

| 模块 | 说明 | 状态 |
|------|------|------|
| 游戏框架 | 状态管理、存档、事件分发、跨局进度 | ✅ |
| 战斗系统 | 回合制战斗、伤害流水线、伤害标签、soft cap | ✅ |
| 玩家系统 | 职业、进化、属性、形态管理 | ✅ |
| 怪物系统 | 怪物AI、特质、Boss战 | ✅ |
| 地图系统 | 楼层探索、事件、签名、特殊楼层 | ✅ |
| 附身系统 | 附身/形态切换/遗产提取 | ✅ |
| 污染系统 | 5阶段污染、被动效果、ATK/DEF倍率 | ✅ |
| 共鸣系统 | 形态共鸣组合、熟练度 | ✅ |
| 遗产系统 | 遗产提取、装备、腐蚀变异 | ✅ |
| 锚点系统 | 死亡回滚、EP消耗 | ✅ |
| 商店系统 | 残响商店、物品购买 | ✅ |
| 成就系统 | 成就解锁、奖励、进度追踪 | ✅ |
| 模式曲线 | Short/Expedition/Classic 难度曲线 | ✅ |

### 1.2 模块关系

```
游戏框架 (GameManager + EventBus + SaveSystem)
    │
    ├── CompleteGameSystem (核心玩法引擎)
    │   ├── 战斗系统 (PlayerAttack/EnemyAttack)
    │   ├── 地图系统 (SeedFloorActions/AdvanceFloor)
    │   ├── 附身系统 (TryPossess)
    │   └── 结算系统 (GenerateRunReport)
    │
    ├── 构筑子系统
    │   ├── PollutionSystem ←→ PollutionPassiveSystem
    │   ├── FormResonanceSystem (共鸣+熟练度)
    │   ├── LegacyManager (遗产)
    │   └── AnchorSystem (锚点)
    │
    ├── 数据层
    │   ├── ModeFloorCurves (难度曲线)
    │   ├── GameDataImporter (怪物定义)
    │   ├── FloorSignatureData (楼层签名)
    │   ├── AltarData (祭坛选项)
    │   └── BuildAxesData (轴线协同)
    │
    └── UI层
        └── CanvasUIManager (20+ partial classes)
```

## 二、核心玩法循环

```
选择职业 → 选择模式(短局/远征/经典) → 进入塔层
    │
    ↓
探索地图 → 遇敌战斗 → 附身/击杀 → 获得形态/遗产/EP
    │           │                        │
    │           ↓                        ↓
    │      切换形态 → 触发共鸣     污染累积 → 被动效果
    │           │                        │
    ↓           ↓                        ↓
进入下层 → 楼层签名/事件/祭坛 → 构筑进化
    │                                    │
    ↓                                    ↓
Boss战 → 通关/死亡 → 结算报告(含构筑回顾)
              │
              ↓
        锚点回滚 / 跨局进度保留
```

## 三、核心数值体系

### 3.1 资源

| 资源 | 获取 | 消耗 |
|------|------|------|
| EP（进化点） | 击杀奖励×epMult | 进化升级、锚点激活 |
| 残响（Echo） | 结算奖励 | 商店购买 |
| 污染值 | 每层累积、附身 | 触发被动、ATK加成 |

### 3.2 伤害计算

详见 [02_战斗系统.md](02_战斗系统.md) — 20步伤害流水线

关键乘法源：
- 污染ATK倍率（×1.0 ~ ×1.5）
- 遗产效果加成
- 共鸣效果加成
- 轴线协同加成
- Soft cap（总倍率>2.0时超出部分×0.6）

## 四、短局节奏设计

4层内体验全部核心系统：

| 层 | 玩家体验的系统 |
|----|--------------|
| F1 | 移动/攻击教程 |
| F2 | 附身（zone2强敌目标） |
| F3 | 遗产（免费赠送） |
| F4 | 共鸣（切换提示） |
| F5+ | 进化/签名/祭坛... |

污染/EP曲线前移，确保快节奏体验。

---

## 五、远征战略深度

20层4章节，含2个固定抉择转折点：

| 转折点 | 层 | 意义 |
|--------|---|------|
| 污染分叉 | F8 | 高污染攻击流 vs 低污染防御流 |
| 最终抉择 | F15 | Boss前战略定型 |
