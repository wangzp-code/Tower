# 商店系统策划文档

## 一、商店类型

### 1.1 商店分类

| 商店类型 | 说明 | 位置 |
|----------|------|------|
| **主商店** | 出售基础道具 | 地图商店楼层 |
| **进化商店** | 出售进化相关道具 | 主菜单 |
| **碎片商店** | 出售碎片 | 地图随机事件 |
| **限时商店** | 出售限时道具 | 特定活动 |
| **残响商店** | 出售高级道具 | 主菜单 |

### 1.2 商店位置

| 位置 | 说明 |
|------|------|
| **地图商店** | 每5层出现一次 |
| **主菜单商店** | 随时可访问 |
| **事件商店** | 随机事件触发 |

## 二、商品系统

### 2.1 商品类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **消耗品** | 一次性使用 | 生命药水、能量药水 |
| **碎片** | 装备类 | 力量碎片、防御碎片 |
| **进化道具** | 进化相关 | 进化石、技能书 |
| **外观道具** | 外观装饰 | 皮肤、头像框 |
| **礼包** | 组合商品 | 新手礼包、进阶礼包 |

### 2.2 商品稀有度

| 稀有度 | 颜色 | 价格倍率 |
|--------|------|---------|
| 普通 | 灰色 | 1x |
| 稀有 | 蓝色 | 2x |
| 史诗 | 紫色 | 4x |
| 传说 | 金色 | 8x |

### 2.3 商品价格

| 货币类型 | 说明 | 用途 |
|----------|------|------|
| **金币** | 基础货币 | 购买普通商品 |
| **进化点** | 高级货币 | 购买进化相关 |
| **特殊货币** | 活动货币 | 购买活动商品 |

## 三、商品配置

### 3.1 商品数据结构

```
ShopItem
├── id: string           # 商品ID
├── name: string         # 商品名称
├── description: string  # 商品描述
├── type: string         # 商品类型
├── rarity: string       # 稀有度
├── price: int           # 价格
├── currency: string     # 货币类型
├── icon: string         # 图标路径
├── effect: string       # 效果描述
└── quantity: int        # 库存数量
```

### 3.2 商品配置示例

| ID | 名称 | 类型 | 价格 | 效果 |
|----|------|------|------|------|
| hp_potion | 生命药水 | 消耗品 | 50金币 | 恢复30%生命 |
| str_fragment | 力量碎片 | 碎片 | 100金币 | 攻击力+5 |
| evolve_stone | 进化石 | 进化道具 | 500金币 | 进化点+100 |

## 四、购买流程

### 4.1 购买步骤

```
购买流程:
1. 进入商店
2. 浏览商品列表
3. 选择商品
4. 确认购买
5. 扣除货币
6. 获得商品
7. 显示购买成功提示
```

### 4.2 购买限制

| 限制类型 | 说明 |
|----------|------|
| **库存限制** | 部分商品限量 |
| **等级限制** | 部分商品需要达到特定进化等级 |
| **货币限制** | 需要足够的货币 |
| **购买次数** | 每日/每周限购 |

### 4.3 购买确认

```
确认弹窗内容:
- 商品名称和图标
- 商品描述
- 价格和货币类型
- 购买数量
- 确认/取消按钮
```

## 五、商店刷新

### 5.1 刷新机制

| 刷新类型 | 说明 |
|----------|------|
| **自动刷新** | 进入新楼层时刷新 |
| **手动刷新** | 消耗金币手动刷新 |
| **时间刷新** | 每日固定时间刷新 |

### 5.2 刷新消耗

```
手动刷新消耗:
- 第1次: 50金币
- 第2次: 100金币
- 第3次: 200金币
- 以此类推...
```

### 5.3 商品池

```
商品池结构:
├── 普通商品池
├── 稀有商品池
├── 史诗商品池
└── 传说商品池

刷新时从对应池子随机抽取
```

## 六、礼包系统

### 6.1 礼包类型

| 礼包类型 | 价格 | 内容 |
|----------|------|------|
| **新手礼包** | 免费 | 基础道具 |
| **进阶礼包** | 19.9元 | 稀有道具 |
| **豪华礼包** | 39.9元 | 史诗道具 |
| **至尊礼包** | 69.9元 | 传说道具 |
| **限定礼包** | 99.9元 | 限定道具 |

### 6.2 礼包内容

```
礼包结构:
├── 名称
├── 描述
├── 价格
├── 内容列表
│   ├── itemId
│   └── quantity
└── 购买限制
```

### 6.3 礼包购买

- **购买限制**: 每个礼包限购一次
- **购买方式**: 内购支付
- **发放方式**: 即时发放到背包
