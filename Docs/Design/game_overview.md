
# 游戏设计概述

## 1. 游戏核心概念

### 1.1 游戏名称
- 中文：寄生塔
- 英文：Parasite Tower

### 1.2 游戏类型
- Roguelike + 卡牌构筑 + 形态切换

### 1.3 核心玩法
玩家扮演一个寄生生物，通过附身不同的怪物来获取能力，在不断被污染的塔中向上攀登。每次死亡后会失去大部分能力，但保留核心职业和部分进度。

## 4. 游戏流程

```
主菜单 → 选择职业 → 开始游戏 → 探索楼层 → 遭遇事件 → 战斗/谈判 → 
获取奖励 → 继续探索 → 死亡/通关 → 返回主菜单
```

---

## 5. 关键设计原则

1. **局内成长 vs 跨局成长**
   - 局内：形态、遗产、临时增益
   - 跨局：职业等级、残响、解锁内容

2. **风险与收益平衡**
   - 高污染 = 高难度 + 高奖励
   - 低污染 = 低难度 + 低奖励

3. **策略深度**
   - 形态组合搭配
   - 遗产效果组合
   - 战斗策略选择
