# 核心框架设计文档

## 一、游戏状态管理

### 1.1 状态定义

来源：`GameManager.GameState`

| 状态 | 说明 | 触发条件 |
|------|------|---------|
| MainMenu | 主菜单 | 游戏启动、返回主菜单 |
| CharacterSelect | 职业选择 | 点击"开始新游戏" |
| ModeSelect | 模式选择 | 选择职业后 |
| Playing | 游戏进行中 | 进入探索/战斗 |
| GameOver | 游戏结束 | 死亡或通关 |
| Paused | 暂停 | 打开菜单 |

### 1.2 状态转换

```
MainMenu → CharacterSelect → ModeSelect → Playing
    ↑                                        │
    └──────────── GameOver ←─────────────────┘
```

### 1.3 CompleteGameSystem 内部状态

来源：`CompleteGameSystem.RunScreen`

| 状态 | 说明 |
|------|------|
| Explore | 地图探索 |
| Combat | 战斗中 |
| Possess | 附身选择 |
| GameOver | 结算画面 |

## 二、存档系统

来源：`SaveSystem.cs`

### 2.1 自动存档

- 每层切换时 `AutoSave()`
- PlayerPrefs 存储

### 2.2 跨局数据

来源：`MetaProgressSystem.cs`

持久化的跨局数据（不随 clearAllGameData 清除）：
- `pt_achievements` — 成就解锁
- `pt_endings` — 已达成结局
- `totalGamesPlayed`, `totalKills`, `maxFloorReached` 等统计
- `classLevel` — 职业等级
- `formBond` — 形态羁绊
- `monstersEncountered` — 怪物图鉴
- `noDeathRuns`, `perfectRuns` — 挑战记录

MetaProgressSystem 每60秒自动 flush dirty data。

## 三、事件系统

来源：`EventBus.cs`

### 3.1 核心事件

| 事件名称 | 参数 | 触发时机 |
|---------|------|---------|
| FloorEntered | floor: int | 进入新楼层 |
| PlayerAttack | - | 玩家攻击 |
| TurnStart | - | 回合开始 |
| FormReplaced | oldFormId, newFormId | 形态替换 |
| LegacySelection | candidates, formId | 遗产选择弹出 |
| PollutionChanged | value: float | 污染值变化 |
| PlayerStatsChanged | - | 玩家属性变化 |

### 3.2 使用模式

```csharp
EventBus.Register<int>(EventTypes.FloorEntered, OnFloorEntered);
EventBus.Emit<int>(EventTypes.FloorEntered, floor);
```

## 四、配置管理

来源：`DataConfigManager.cs`

### 4.1 配置文件

| 配置文件 | 内容 | 加载路径 |
|---------|------|---------|
| MonsterBase.json | 怪物基础数据 | StreamingAssets/Config/ |
| FloorEvent.json | 楼层事件配置 | StreamingAssets/Config/ |
| FormResonanceConfig.json | 共鸣组合定义 | StreamingAssets/Config/ |
| LegacyConfig.json | 遗产模板配置 | StreamingAssets/Config/ |
| BossPhaseConfig.json | Boss阶段配置 | StreamingAssets/Config/ |
| RunReportConfig.json | 结算报告配置 | StreamingAssets/Config/ |

### 4.2 硬编码数据

部分核心数据在代码中硬编码（有JSON备选）：
- `ModeFloorCurves.cs` — 模式难度曲线
- `FloorSignatureData` — 楼层签名（在 OriginalWebViewData.cs）
- `AltarData` — 祭坛选项（在 ProgressionData.cs）
- `ClassAbilityData` — 职业能力
- `BuildAxesData` — 构筑轴线协同
- `GameDataImporter.FallbackDefinitions` — 怪物数据兜底
