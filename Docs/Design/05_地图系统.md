# 地图与楼层系统设计文档

## 一、游戏模式

来源：`GameMode` 枚举 + `ModeFloorCurves.cs`

| 模式 | 层数 | 定位 |
|------|------|------|
| Short（短局） | 12层 | 快节奏拉新体验，4层内展示全部核心系统 |
| Expedition（远征） | 20层 | 4章节深度体验，含固定抉择事件 |
| Classic（经典） | 50层 | 完整递归，高难度挑战 |

详细曲线参数见 [mode_curves.md](mode_curves.md)

## 四、楼层事件系统

来源：`FloorEventManager.cs` + `FloorEvent.json`

每层进入时 `TryTriggerEvent(floor)` 按概率触发事件。

事件类型：choice / reward / risk / shop / challenge / story

事件触发后弹出事件面板 `ShowFloorEventPanel()`。

## 五、远征固定抉择事件

来源：`CompleteGameSystem.cs` AdvanceFloor

### 5.1 第8层 — 污染分叉

二选一（复用祭坛UI）：
- **☢ 污染注入**：+25%污染，获得一个rarity=2的腐蚀遗产
- **✦ 净化仪式**：-15%污染

### 5.2 第15层 — 最终抉择

二选一（复用祭坛UI）：
- **⚔ 全力一搏**：污染→85%，ATK翻倍
- **🛡 稳健通关**：回复50%HP，污染→30%，DEF+50%

## 六、怪物生成

来源：`SeedFloorActions()` + `CreateMonsterForFloor()`

### 6.1 怪物数量

由曲线 `monsterCount` 字段控制（短局F1=4, F12=7）。

### 6.2 怪物选择

- 从 `MonsterDefinitions` 按 `zone` 筛选
- Boss层最后一只强制为Boss
- 精英概率由曲线 `eliteRate` 控制（F5起生效）

### 6.3 短局第2层保底

短局F2额外插入一个zone2强敌（★标记、附身概率0.75），作为明确的附身目标。

### 6.4 楼梯守卫

出口附近 1-3 只守卫（HP×0.7, ATK×0.8），阻挡快速通关。

### 6.5 祭坛

每5层非Boss层生成一个祭坛事件点。

## 七、地图UI

- 12×12 网格地图，迷雾覆盖

- 签名标签显示在层信息中：`第N层 — [签名名称]`
