
# 商店系统设计文档

## 1. 系统概述

### 1.1 设计目的
商店系统提供玩家消耗资源购买道具、升级和解锁内容的途径。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| 残响 | 游戏主要货币，通过战斗、登录等获得 |
| 商品 | 可购买的物品、升级、解锁内容 |
| 礼包 | 组合商品，提供优惠价格 |
| 限购 | 部分商品有购买次数限制 |

### 3.2 购买流程

**购买步骤：**
```
选择商品 → 检查货币是否足够 → 
检查限购次数 → 扣除货币 → 
发放物品 → 更新限购计数 → 
刷新UI
```

**购买逻辑** - [ShopManager.cs](file:///Users/wangzhipeng/tower/Assets/Scripts/Runtime/Shop/ShopManager.cs)
```csharp
bool PurchaseItem(ShopItemData item)
{
    int balance = PlayerPrefs.GetInt("pt_meta_echoes", 0);
    
    if (balance < item.price)
        return false;
    
    if (item.limit > 0 && GetPurchaseCount(item.id) >= item.limit)
        return false;
    
    // 扣除货币
    PlayerPrefs.SetInt("pt_meta_echoes", balance - item.price);
    
    // 发放物品
    ApplyItem(item.type, item.value);
    
    // 更新限购计数
    UpdatePurchaseCount(item.id);
    
    PlayerPrefs.Save();
    return true;
}
```

## 5. 设计决策

### 5.1 价格梯度
- **低价位**：9.99、19.99元（吸引小额消费）
- **中价位**：29.99、39.99元（主力消费）
- **高价位**：69.99、99.99元（大额消费）

### 5.2 限购设计
- **理由**：控制商品获取节奏，保持游戏平衡
- **实现**：记录购买次数，定期重置

### 5.3 礼包设计
- **理由**：提供更高性价比的选择，促进消费
- **实现**：组合多种物品，给予折扣

## 7. 与其他系统的交互

### 7.1 与成就系统
- 购买商品可能解锁成就
- 成就奖励可能包含残响

### 7.2 与每日登录系统
- 每日登录奖励残响
- 商店可能有每日特价商品

### 7.3 与形态系统
- 商店可购买形态碎片
- 购买后解锁新形态
