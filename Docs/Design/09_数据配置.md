# 数据配置策划文档

## 一、配置文件结构

### 1.1 配置文件列表

| 文件名称 | 内容 | 格式 |
|----------|------|------|
| GameConfig.json | 游戏基础配置 | JSON |
| MonsterBase.json | 怪物基础数据 | JSON |
| ShopItems.json | 商店物品配置 | JSON |
| FloorEvent.json | 楼层事件配置 | JSON |
| LegacyConfig.json | 传承系统配置 | JSON |
| BossPhaseConfig.json | Boss阶段配置 | JSON |
| CorruptionSkill.json | 腐化技能配置 | JSON |
| HostProfile.json | 宿主配置 | JSON |

### 1.2 配置管理

| 职责 | 说明 |
|------|------|
| **配置加载** | 游戏启动时加载所有配置 |
| **配置缓存** | 运行时缓存配置数据 |
| **配置热更** | 支持运行时重新加载 |
| **版本校验** | 校验配置版本一致性 |

## 二、游戏基础配置

### 2.1 GameConfig 结构

```json
{
  "gameVersion": "1.0.0",
  "classicModeFloorCount": 50,
  "dailyRewardDays": 9,
  "maxPollution": 100,
  "combatConfig": {
    "baseEpReward": 15,
    "epPerZone": 20,
    "epRandomRange": 10,
    "eliteEpMultiplier": 1.8,
    "swarmEpBonusL2": 5,
    "swarmEpBonusL5": 10
  },
  "playerConfig": {
    "maxHp": 9999,
    "maxAtk": 999,
    "maxDef": 999,
    "maxEva": 50,
    "maxCri": 100
  }
}
```

### 2.2 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| gameVersion | 游戏版本号 | 1.0.0 |
| classicModeFloorCount | 经典模式楼层数 | 50 |
| dailyRewardDays | 每日签到天数 | 9 |
| maxPollution | 最大污染值 | 100 |
| baseEpReward | 基础进化点奖励 | 15 |
| epPerZone | 每楼层进化点加成 | 20 |

## 三、怪物配置

### 3.1 MonsterBase 结构

```json
{
  "monsters": [
    {
      "id": "slime",
      "name": "史莱姆",
      "type": "melee",
      "zone": 1,
      "baseHp": 30,
      "baseAtk": 8,
      "baseDef": 2,
      "intentTypes": ["attack", "defend"],
      "traits": [],
      "dropRate": 0.3
    }
  ]
}
```

### 3.2 怪物属性说明

| 属性 | 说明 |
|------|------|
| id | 怪物唯一ID |
| name | 怪物名称 |
| type | 怪物类型(melee/ranged/defense/heal) |
| zone | 最低出现楼层 |
| baseHp | 基础生命值 |
| baseAtk | 基础攻击力 |
| baseDef | 基础防御力 |
| intentTypes | 可能的意图类型 |
| traits | 怪物特性列表 |
| dropRate | 碎片掉落率 |

## 六、Boss阶段配置

```json
{
  "bosses": [
    {
      "id": "boss1",
      "name": "第一层守护者",
      "phases": [
        {
          "hpThreshold": 100,

          "hpThreshold": 50,
          "actions": ["heavy_attack", "attack", "skill"],
          "skillChance": 0.5

    }
  ]

```

### 6.2 Boss阶段说明

| 属性 | 说明 |
|------|------|
| id | Boss唯一ID |
| name | Boss名称 |
| phases | 阶段列表 |
| hpThreshold | 阶段触发血量阈值 |
| actions | 可用行动列表 |
| skillChance | 技能释放概率 |

## 七、配置加载流程

### 7.1 加载流程

```
加载流程:
1. 游戏启动
2. Bootstrap初始化
3. ConfigManager加载配置文件
4. 解析JSON数据
5. 缓存配置对象
6. 提供全局访问接口
```

### 7.2 配置访问

```
访问方式:
- ConfigManager.Instance.GetGameConfig()
- ConfigManager.Instance.GetMonsterConfig(id)
- ConfigManager.Instance.GetShopItemConfig(id)
```

### 7.3 配置热更新

```
热更新流程:
1. 检测配置文件变化
2. 重新加载配置文件
3. 更新缓存数据
4. 通知相关系统配置已更新
```
