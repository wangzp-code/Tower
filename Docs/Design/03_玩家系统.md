# 玩家系统设计文档

## 一、职业系统

### 1.1 职业列表

| 职业ID | 名称 | 定位 | 核心特点 |
|--------|------|------|---------|
| titan | 泰坦 | 防御型 | 高HP高DEF，每层被动加防 |
| ghost | 幽灵 | 爆发型 | 高ATK低DEF，暗杀向 |
| swarm | 虫群 | 持续型 | 多段攻击，毒素协同 |
| blood | 血族 | 续航型 | 血怒+吸血，HP<30%时ATK+50% |
| mech | 机甲 | 均衡型 | 均衡属性，护甲加成 |

### 1.2 职业初始属性

来源：`OriginalGameData.cs` ClassBaseStats

| 属性 | 泰坦 | 幽灵 | 虫群 | 血族 | 机甲 |
|------|------|------|------|------|------|
| HP | 45 | 28 | 35 | 32 | 40 |
| ATK | 3 | 5 | 4 | 6 | 4 |
| DEF | 3 | 1 | 1 | 1 | 2 |

### 1.3 职业被动

来源：`ClassAbilityData.cs`

- **泰坦**: 每层+DEF，进化后格挡概率增加
- **幽灵**: 首击加倍概率，进化后暗杀加成
- **虫群**: 多段攻击概率，进化后毒叠加
- **血族**: HP<30%时ATK×1.5（血怒），进化Lv3+高污染时吸血×1.5
- **机甲**: 护甲回合加成，进化后反击概率

## 二、进化系统

### 2.1 进化机制

来源：`CompleteGameSystem.cs` EvolutionLevel

- 消耗 EP（进化点）升级，当前等级通过 `GetNextEvolutionNode().epCost` 获取
- 最高5级（epCost=9999表示已满级）

### 2.2 进化效果

| 等级 | 效果 |
|------|------|
| Lv2 | 遗产槽位+1，遗产效果×1.1 |
| Lv3 | 共鸣持续+1回合 |
| Lv4 | 遗产槽位+2，遗产效果×1.25 |
| Lv5 | 共鸣效果×1.5，共鸣持续再+1回合 |

### 2.3 EP获取

- 击杀怪物（基础奖励 × 曲线epMult）
- 楼层签名加成（如"黄金雨"EP×3）
- 附身时部分事件给EP
- 曲线前移：短局前4层 epMult = 2.0 / 1.8 / 1.6 / 1.3

## 三、属性系统

### 3.1 基础属性

| 属性 | 说明 |
|------|------|
| HP/maxHp | 生命值 |
| ATK (attack/baseAttack) | 攻击力 |
| DEF (defense/baseDefense) | 防御力 |
| pollution | 污染值 0-100% |
| evolutionPoints | 进化点 |
| lifesteal | 吸血倍率 |
| possessionBonus | 附身成功率加成 |

### 3.2 属性计算

```
最终ATK = baseAttack × 污染ATK倍率 × 楼层签名ATK倍率
最终DEF = baseDefense × 污染DEF倍率 × 楼层签名DEF倍率
```

## 四、形态系统

详见 [form_system.md](form_system.md)

- 初始形态：human（寄生体）
- 通过附身获得新形态，`ownedForms` 列表管理
- 形态切换触发共鸣效果（详见 [resonance_system.md](resonance_system.md)）
- 连续使用同一形态3回合+获得熟练度加成（每3回合+5%，上限25%）

---

## 五、污染系统

详见 [pollution_system.md](pollution_system.md)

核心要点：
- 5个阶段：净化(<30) / 觉醒(30-59) / 侵蚀(60-84) / 临界(85-99) / 爆发(100)
- 影响ATK/DEF倍率，触发被动效果
- 净化阶段：每回合+2%HP回复
- 临界/爆发：遗产腐蚀风险，共鸣增幅

## 六、死亡与存续机制

### 6.1 记忆锚点系统

详见 [anchor_system.md](anchor_system.md)

- 死亡时如果有EP且有锚点，可消耗EP回滚到锚点层
- 回滚后保留形态和遗产，但锚点标记为已用

### 6.2 遗产系统

详见 [legacy_system.md](legacy_system.md)

- 替换形态时从旧形态提取遗产能力
- 遗产槽位随进化等级增加（2→4）
- 高污染时遗产可能腐蚀变异

### 6.3 跨局进度

来源：`MetaProgressSystem.cs`

跨局保留的数据：
- 成就解锁状态（`pt_achievements`）
- 已达成结局（`pt_endings`）
- 已遇怪物图鉴（`monstersEncountered`）
- 职业等级（`classLevel`）
- 形态羁绊（`formBond`）
- 总游戏场次、总击杀、无死亡通关次数等统计

**注意**：`clearAllGameData` 不得清除跨局数据。
