# 怪物系统策划文档

## 一、怪物类型

### 1.1 怪物分类

| 分类 | 特点 | 例子 |
|------|------|------|
| **普通怪物** | 基础属性 | 史莱姆、蝙蝠、老鼠 |
| **精英怪物** | 增强属性 | 精英史莱姆、变异蝙蝠 |
| **Boss怪物** | 高难度、特殊技能 | 各层Boss |
| **Boss随从** | Boss战中的小怪 | 召唤物、分身 |

### 1.2 怪物类型

| 类型 | 图标 | 特点 |
|------|------|------|
| **近战型** | 剑 | 高攻击、低防御 |
| **远程型** | 弓 | 低血量、高伤害 |
| **防御型** | 盾 | 高防御、低攻击 |
| **治疗型** | 心 | 可治疗同伴 |
| **特殊型** | 星 | 特殊技能效果 |

### 1.3 怪物分布

| 楼层范围 | 怪物强度 | 代表怪物 |
|---------|---------|---------|
| 1-5 | 低 | 史莱姆、蝙蝠 |
| 6-10 | 中 | 狼、蜘蛛 |
| 11-15 | 中高 | 骷髅、巨魔 |
| 16-20 | 高 | 死亡骑士、泰坦 |
| 21+ | 极高 | Boss级怪物 |

## 二、怪物属性

### 2.1 基础属性

| 属性 | 说明 |
|------|------|
| **生命值** | 怪物血量 |
| **攻击力** | 攻击伤害 |
| **防御力** | 减伤能力 |
| **速度** | 行动顺序 |
| **楼层** | 所属楼层 |
| **类型** | 近战/远程/防御/治疗 |

### 2.2 属性计算

```
怪物属性 = 基础属性 × 楼层系数
楼层系数 = 1 + (楼层-1) × 0.1
```

### 2.3 精英怪物增强

```
精英怪物属性 = 普通怪物 × 1.5
精英怪物额外获得:
- 一个特殊特性
- 颜色变化
- 血条边框变化
```

## 三、怪物AI系统

### 3.1 AI行为模式

| 模式 | 说明 | 行为特点 |
|------|------|---------|
| **攻击型** | 优先攻击 | 直接攻击玩家 |
| **防御型** | 优先防御 | 先提升防御 |
| **治疗型** | 优先治疗 | 治疗受伤同伴 |
| **策略型** | 根据情况选择 | 智能选择行动 |

### 3.2 AI决策流程

```
1. 评估当前状态
2. 选择行动意图
3. 执行行动
4. 更新状态
```

### 3.3 意图生成

| 意图类型 | 触发条件 |
|----------|---------|
| 攻击 | 玩家血量 > 30% |
| 重击 | 玩家血量 > 50% |
| 防御 | 自身血量 < 50% |
| 治疗 | 同伴血量 < 30% |
| 特殊 | 特定条件触发 |

## 四、怪物特性系统

### 4.1 特性类型

| 特性类型 | 效果 |
|----------|------|
| **攻击特性** | 增加攻击伤害 |
| **防御特性** | 减少受到伤害 |
| **特殊特性** | 特殊效果 |
| **负面特性** | 对玩家造成debuff |

### 4.2 特性列表

| 特性名称 | 效果 |
|----------|------|
| 狂暴 | 血量低于30%时伤害+50% |
| 再生 | 每回合恢复5%生命 |
| 反射 | 反弹20%受到伤害 |
| 剧毒 | 攻击附带中毒效果 |
| 护盾 | 战斗开始获得护盾 |
| 吸血 | 攻击时恢复生命 |
| 召唤 | 可召唤小怪 |
| 免疫 | 对某些伤害免疫 |

### 4.3 特性获取

- **普通怪物**: 随机获得0-1个特性
- **精英怪物**: 随机获得1-2个特性
- **Boss怪物**: 固定拥有多个特性

## 五、Boss系统

### 5.1 Boss特性

| 特点 | 说明 |
|------|------|
| **多阶段** | 不同血量阶段不同行为 |
| **特殊技能** | 独特的Boss技能 |
| **随从召唤** | 可召唤小怪协助战斗 |
| **高血量** | 远超普通怪物 |

### 5.2 Boss阶段

```
阶段1: 100% - 70%血量 → 普通攻击模式
阶段2: 70% - 40%血量 → 增强攻击模式
阶段3: 40% - 0%血量 → 狂暴模式
```

### 5.3 Boss技能

| 技能类型 | 说明 |
|----------|------|
| **范围攻击** | 对玩家造成大量伤害 |
| **debuff技能** | 施加负面状态 |
| **召唤技能** | 召唤随从 |
| **必杀技** | 超高伤害技能 |
