# 战斗系统设计文档

## 一、战斗核心机制

### 1.1 战斗流程

来源：`CompleteGameSystem.cs` PlayerAttack / EnemyAttack

```
进入战斗 → 玩家攻击 → 敌人回合 → 判定胜负 → 战利品/附身窗口
```

### 1.2 战斗状态

| 状态 | 说明 |
|------|------|
| Explore | 地图探索中 |
| Combat | 战斗进行中 |
| Possess | 附身选择窗口 |
| GameOver | 游戏结束 |

## 二、伤害计算流水线

来源：`CompleteGameSystem.cs` PlayerAttack (line ~933)

完整伤害计算链：

```
1. baseAtk = player.attack
2. [血族] HP<30% → baseAtk ×1.5 (血怒)
3. finalAtk = baseAtk × FloorSignatureAtkMult
4. rawDamage = max(1, finalAtk - effectiveDef)
   - [护甲特质] 前3回合 effectiveDef ×2
5. damage = rawDamage × (1 + comboBonus)
6. [赌徒天堂签名] damage × random(0.5~2.0)
7. [脆弱结界签名] damage × dmgMult
8. [暴击场签名] 30%概率 damage ×2
9. [持久战] 超过6回合后 +maxHP×8%×超出回合数
10. [铁壁特质] 10%概率完全格挡 → damage=0
11. [职业被动] ClassAbilityData.ApplyPassiveOnAttack
12. [特质钩子] TraitEffects.ApplyOnPlayerAttack
13. [轴线协同] BuildAxesData.GetSynergyBonus → damage × (1+bonus)
14. [遗产Boss伤害] isBoss时 → damage × (1+bossBonusLegacy)
15. [共鸣ATK加成] → damage × (1+resonanceAtkBoost)
16. [共鸣无视防御] → damage + defIgnored
17. [共鸣暴击] → 概率 damage ×2
18. [共鸣二连击] → damage + bonusDmg
19. [Soft Cap] rawDamage>0 && damage > rawDamage×2 → 超出部分×0.6
20. CurrentEnemy.hp -= damage
21. [共鸣毒DOT] → 额外 maxHP×poisonRate 伤害
```

### 2.1 Soft Cap 机制

防止多层乘法雪球：
```csharp
if (rawDamage > 0 && damage > rawDamage * 2)
    damage = rawDamage * 2f + (damage - rawDamage * 2f) * 0.6f;
```

极端 ×3.4 → 实际 ×2.84，仍然强力但不会秒杀Boss。

## 三、伤害来源标签

来源：PlayerAttack 中 `dmgTags` 列表

战斗日志自动附加加成来源标签，帮助玩家理解伤害构成：

| 标签 | 触发条件 | 显示格式 |
|------|---------|---------|
| ♦血怒 | 血族HP<30% | 红色 |
| 连击+N% | comboBonus > 0 | 金色 |
| 轴线+N% | 轴线协同匹配 | 浅蓝 |
| ★Boss+N% | 遗产Boss伤害加成 | 金色 |
| ◈共鸣+N% | 共鸣ATK加成激活 | 青色 |

日志示例：`R5 你→42 对 培育狼 造成 42 点伤害 ◈共鸣+20% 轴线+15%`

## 五、连击系统

来源：`GetComboBonus()`, `_comboCount`, `_comboTimer`

- 连续攻击命中累加 `_comboCount`
- `_comboTimer = 2f` 每次攻击刷新，超时归零
- 连击加成按 comboCount 线性增长

## 六、特质效果

来源：`TraitEffects.cs`

怪物特质影响战斗：

| 特质 | 效果 |
|------|------|
| 护甲 | 前3回合DEF×2 |
| 铁壁 | 10%概率完全格挡 |
| 再生 | 每回合回复HP |
| 狂暴 | ATK提升但DEF降低 |
| 毒素 | 攻击附带中毒DOT |
| 吸血 | 攻击回复HP |
| 相位 | 概率闪避攻击 |
| 多重攻击 | 一回合攻击多次 |

## 七、附身窗口

来源：PlayerAttack 中 breakWindow 逻辑

- 敌人HP首次低于50%时触发破防窗口
- 附身基础概率 60%（`possessBaseChance = 0.6f`）
- 加成来源：`possessionBonus`、楼层签名（如"寄生乐园"+20%）
- 附身成功后获得该形态、触发遗产提取

---

## 八、战斗奖励

来源：`CalculateCombatReward()`

- EP = 基础值 × 曲线epMult × 楼层签名epMult
- 精英怪物：奖励加成
- Boss：额外大量EP和掉落
- 楼层签名影响：黄金雨(×3)、进化加速(×2)等

---

## 九、结算报告

来源：`GenerateRunReport()`

死亡/通关时生成报告，包含：
- 到达层数、击杀数、附身次数
- 存活时长、最久宿主
- 最高污染、最终形态
- 评分（层数×10 + 击杀×5 + 附身×15 + EP/10 + 通关200）
- 评级：C / B / A / S / SS / SSS
- **构筑回顾**：污染阶段、收集形态数、遗产组合
