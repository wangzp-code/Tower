# UI界面策划文档

## 一、主菜单界面

### 1.1 界面结构

```
主菜单:
├── 顶部信息栏
│   ├── 玩家名称
│   ├── 进化点
│   └── 污染值
├── 中间区域
│   ├── 角色立绘
│   ├── 当前宿主名称
│   └── 开始新一轮下潜按钮
├── 功能按钮区
│   ├── 记忆
│   ├── 挑战
│   ├── 圣坛
│   ├── 记录
│   ├── 签到
│   └── 排行
└── 底部导航栏
    ├── 成就
    ├── 图鉴
    ├── 下潜
    ├── 设置
    └── 商店
```

### 1.2 交互流程

```
主菜单交互:
1. 点击"下潜"按钮 → 进入游戏
2. 点击"签到"按钮 → 打开签到面板
3. 点击"商店"按钮 → 打开商店界面
4. 点击"成就"按钮 → 打开成就界面
5. 点击"图鉴"按钮 → 打开图鉴界面
6. 点击"设置"按钮 → 打开设置界面
```

## 七、通用UI组件

### 7.1 按钮组件

| 类型 | 说明 | 样式 |
|------|------|------|
| **普通按钮** | 基础操作按钮 | 圆角矩形 |
| **主要按钮** | 重要操作按钮 | 发光效果 |
| **次要按钮** | 次要操作按钮 | 灰色背景 |
| **图标按钮** | 仅显示图标 | 圆形 |

### 7.2 进度条组件

| 类型 | 说明 | 样式 |
|------|------|------|
| **生命值条** | 显示血量 | 绿色渐变 |
| **能量条** | 显示能量 | 蓝色渐变 |
| **污染条** | 显示污染值 | 紫色渐变 |
| **成就进度条** | 显示成就进度 | 金色渐变 |

### 7.3 弹窗组件

| 类型 | 说明 | 样式 |
|------|------|------|
| **确认弹窗** | 确认操作 | 居中显示 |
| **提示弹窗** | 显示提示信息 | 顶部显示 |
| **详情弹窗** | 显示详细信息 | 居中显示 |
| **加载弹窗** | 显示加载状态 | 全屏半透明 |
