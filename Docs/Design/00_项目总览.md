# 寄生塔游戏项目策划文档

## 一、项目概述

### 1.1 项目名称
**寄生塔** (Parasite Tower)

### 1.2 游戏类型
Roguelike 卡牌战斗 + 角色养成

### 1.3 核心玩法
玩家扮演寄生体，通过吞噬怪物获得能力，不断深入塔层，击败守卫Boss。

### 1.4 目标用户
核心玩家群体：Roguelike爱好者、卡牌游戏玩家、轻度策略玩家

---

## 二、项目架构

### 2.1 分层结构

```
项目根目录
├── Assets/                    # Unity 资源目录
│   ├── Art/                   # 美术资源（角色、UI、特效）
│   ├── Audio/                 # 音频资源（BGM、音效）
│   ├── Prefabs/               # 预制件
│   ├── Resources/             # 运行时加载资源
│   ├── Scenes/                # 游戏场景
│   ├── ScriptableObjects/     # 可配置数据资产
│   ├── Scripts/               # 代码脚本
│   │   ├── Editor/            # 编辑器工具
│   │   └── Runtime/           # 运行时代码
│   ├── Shaders/               # 自定义着色器
│   └── StreamingAssets/       # 流式资源（配置JSON）
├── Docs/                      # 文档目录
│   └── Design/                # 策划文档
└── Packages/                  # 包管理器配置
```

### 2.2 代码模块划分

| 模块 | 职责说明 | 关键文件 |
|------|---------|---------|
| **Core** | 核心框架（游戏状态、存档、事件系统） | GameManager, SaveSystem, EventBus |
| **UI** | 用户界面（菜单、战斗UI、HUD） | CanvasUIManager, GameHUD, CombatUI |
| **Combat** | 战斗系统（回合制、技能、意图） | CombatManager, MonsterIntentSystem |
| **Gameplay** | 游戏玩法（地图探索、碎片系统） | CompleteGameSystem, FragmentSystem |
| **Player** | 玩家系统（属性、进化、污染） | PlayerController, PollutionSystem |
| **Monster** | 怪物系统（AI、行为、特性） | MonsterAI, MonsterBase |
| **Shop** | 商店系统（商品、购买逻辑） | ShopManager, ShopUI |
| **Achievements** | 成就系统（解锁、奖励） | AchievementManager |

## 三、核心玩法流程

```
开始游戏 → 选择职业 → 进入塔层 → 探索地图 → 遭遇战斗 → 获得奖励 → 继续深入 → 击败Boss
```

### 3.1 游戏循环
1. **入口阶段**：主菜单 → 新游戏/继续游戏
2. **探索阶段**：地图移动 → 触发事件（战斗/商店/事件）
3. **战斗阶段**：回合制卡牌战斗 → 胜负判定
4. **奖励阶段**：获得碎片/进化点/金币
5. **结算阶段**：楼层结算 → 进入下一层

### 3.2 核心资源

| 资源 | 用途 | 获取方式 |
|------|------|---------|
| **进化点(EP)** | 解锁技能、进化形态 | 战斗奖励、每日签到 |
| **金币** | 购买商店物品 | 战斗奖励、事件奖励 |
| **污染值** | 解锁腐化技能 | 战斗中累积 |
| **碎片** | 强化角色属性 | 战斗掉落 |
